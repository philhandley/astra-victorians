# Astra Victorians

A Year 2 Victorians homework kit: a page for each task with read-aloud facts, ideas and A4 sheets to print, and real
Victorian buildings in 3D to look inside, with paper cut-out models that fold.

Live at https://philhandley.github.io/astra-victorians/ . Install it from the Install app button on the front page.

Pictures are public domain or Creative Commons (see the credits on the grown-ups page). Ordnance Survey map extracts
are from the National Library of Scotland, CC-BY. No accounts, no tracking: ticks are saved on the device only.
